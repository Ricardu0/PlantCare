# 🌱 PlantCare - Sistema de Gerenciamento de Plantas 
 
Sistema completo para gerenciamento e controle de cuidados com plantas. 
 
## 🚀 Tecnologias 
 
- Backend: Node.js + Express + SQLite 
- Frontend: React Native + Expo + TypeScript 
 
## 📦 Instalação 
 
### Backend 
```bash 
cd backend 
npm install 
node server.js
 

Frontend 

cd frontend 
npm install 
npm start 
 

📱 Funcionalidades 

✅ Cadastro de plantas 

✅ Controle de rega 

✅ Categorização 

✅ Lembre-te de regas
